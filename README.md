# gestion-location-vehicules
gestion de location de véhicules en Python, avec récupération des données véhicule (marque, modèle, année) à partir du VIN via l'API NHTSA
Fonctionnalités
. Ajouter un véhicule (manuellement ou via l'API NHTSA)
. Afficher la liste des véhicules
. Supprimer un véhicule (et ses locations associées)
. Ajouter / supprimer un client
. Louer un véhicule disponible (calcul automatique du montant total)
. Supprimer une location (le véhicule redevient disponible)
. Afficher toutes les locations
. Sauvegarder / recharger les données manuellement
